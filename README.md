This code takes data from WordPress Playground using Fluent forms and sends it to Python, this can be see in the png image with the IP-address redacted.

The data is sent in JSON and sorted via Python which communicates with Manger.io, creating a customer and respective sales quote. 
The data I use for this is customer address, name, phone number and email which is inputted to the form here: https://playground.wordpress.net/scope:ambitious-hip-town/membership-form/

Unfortunately due to restrictions with my current laptops firewall I couldn't test the functionality but in practice I belive it works given the API documentation.
